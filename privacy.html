Kebijakan Privasi

Gadget Inaja Autopost — berlaku sejak 26 Juli 2026

Gadget Inaja Autopost ("aplikasi ini") adalah alat otomatisasi pribadi yang merangkum berita teknologi dari umpan RSS publik dan mengunggahnya sebagai video ke akun TikTok milik operatornya sendiri. Aplikasi ini tidak memiliki pengguna publik, tidak memiliki halaman pendaftaran, dan tidak menawarkan layanan kepada pihak ketiga.

Data yang diproses

  • Token TikTok. Aplikasi menyimpan access token dan refresh token milik akun TikTok operator. Keduanya disimpan sebagai encrypted secret di GitHub Actions dan hanya dipakai untuk mengunggah video ke akun tersebut.
  • Informasi akun dasar. Aplikasi membaca nama tampilan dan pengaturan privasi yang diizinkan melalui endpoint creator_info, semata-mata untuk memastikan unggahan masuk ke akun yang benar dan memakai tingkat privasi yang diizinkan.
  • Konten berita publik. Judul, ringkasan, gambar, dan tautan dari umpan RSS yang tersedia untuk umum.

Data yang tidak dikumpulkan

Aplikasi ini tidak mengumpulkan data dari pengguna TikTok lain. Tidak ada pelacakan, tidak ada analitik pihak ketiga, tidak ada cookie, tidak ada profil pengguna, dan tidak ada iklan. Aplikasi tidak membaca video, komentar, pesan, maupun daftar pengikut siapa pun.

Pembagian data

Tidak ada data yang dijual, disewakan, atau dibagikan ke pihak ketiga. Data hanya melewati layanan yang diperlukan agar aplikasi berjalan:

  • TikTok — menerima video, deskripsi, dan token untuk mengunggah.
  • GitHub Actions — menjalankan skrip dan menyimpan secret terenkripsi.
  • Google Gemini — menerima judul dan ringkasan berita publik untuk diterjemahkan dan dirangkum. Tidak ada data pribadi yang dikirim.
  • Microsoft Edge TTS — menerima teks ringkasan untuk diubah menjadi suara. Tidak ada data pribadi yang dikirim.

Penyimpanan dan retensi

Token disimpan selama integrasi masih aktif dan dirotasi otomatis setiap kali TikTok menerbitkan token baru. Berkas video hasil render bersifat sementara dan dihapus setelah proses selesai. Riwayat tautan berita yang sudah diposting disimpan hanya untuk mencegah duplikasi dan tidak mengandung data pribadi.

Menarik akses

Operator dapat mencabut izin aplikasi kapan saja melalui pengaturan akun TikTok (Security & permissions → Manage app permissions). Setelah dicabut, token menjadi tidak berlaku dan aplikasi tidak lagi dapat mengakses akun tersebut. Untuk menghapus token yang tersimpan, hapus secret terkait dari repositori GitHub.
